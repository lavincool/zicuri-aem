# Demo photographs

These 58 photographs illustrate simulated flood and drainage reports. They may depict other
places and dates; they are not evidence of an incident at a report's coordinates.

The complete per-file attribution is in `src/config/demo-photos.json`: original author,
Wikimedia Commons source page, license, and license URL where applicable. Each photograph and
its thumbnail retain that original license, including CC BY-SA for the corresponding
derivatives. Public-domain photographs remain in the public domain.

Changes: resized to a maximum dimension of 1200 px, converted to WebP (full photograph) and
JPEG (480 px thumbnail), with embedded metadata removed. No generated imagery is included.
The report detail displays the source, author, license link and this adaptation notice.

Geographic seed data is separately attributed to © OpenStreetMap contributors (ODbL) in
`data/scenario-places.json`.
